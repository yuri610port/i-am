# I am

**自分の好み、価値観、考え方を、AIと話しながら育てるスキル。**

AIに文章を頼んだとき、「間違ってはいない。でも自分の言葉じゃない」と感じることがあります。
I am は、その違和感を手掛かりに、何を大切にする人なのか、どう考え、どう伝えたいのかを残します。
目指すのは、あなたの視点を踏まえて一緒に考えられる「もう一人の自分」に近づけることです。
口調だけでなく、判断した理由や、迷ったときの優先順位も扱います。

このリポジトリは**個人データが入っていない公開用のひな形**です。記入したプロフィールは、公開リポジトリの外に保存してください。実例はすべて架空です。

## 今回の目的から始める

- **仕組みを整えたい**：スキル、空のひな形、保存・読み込み手順の差分を作ります。整備に必要な材料が揃ったら、質問を止めて差分提案へ進みます。
- **自分を理解する対話をしたい**：今の文章や選択を手掛かりに、話したい範囲で理由を整理します。
- **文章や選択に使いたい**：今回の返信や提案を作ります。プロフィールの全欄が埋まるまで待つ必要はありません。

初回導入や保存先の見直しには [初期設定の手順](skills/i-am/references/setup.md) を使います。AIが保存先・既存情報・許可範囲・読み取りや訂正の結果を確認し、本人しか決められないことだけ質問します。会話内の案だけで始めることもできます。

## まずは一つ、話してみる

特別なアプリやプログラミングは不要です。次の4ファイルを開いて内容をAIに渡し、下の文章を送ってください。

- [スキル本体](skills/i-am/SKILL.md)
- [初期設定の手順](skills/i-am/references/setup.md)
- [記入するひな形](skills/i-am/assets/profile-template.md)
- [質問の進め方](skills/i-am/references/interview.md)

```text
I am を使って、私のプロフィールを一緒に作ってください。
まず、最近「これは自分らしい／自分らしくない」と感じた文章や選択について、一つ質問してください。
私がすでに話したことは聞き直さず、答えから分かったことを短く記録してください。
AIの推測は未確認として分け、分からない項目は空欄のままにしてください。
プロフィールは公開せず、まずこの会話で記入版を見せてください。
```

答えは短くても、音声でも構いません。全部を一度に埋める必要はありません。
AIが保存できない環境では、記入版を自分の非公開メモに保存します。次の会話では、その記入版とスキルを渡してください。ファイルを作るだけで全サービスが自動で記憶するわけではありません。

Agent Skills対応の環境では、`skills/i-am` フォルダーをその環境のスキルとして読み込めます。導入先の指定方法は各環境の案内に従ってください。プロフィールの保存場所はスキル本体とは別に指定します。

## 育て方

1. **話す** — 実際の文章、好きなもの、迷った選択を一つ持ち込む。
2. **理由を見つける** — 何が好きかだけでなく、なぜそう思うのかを聞いてもらう。
3. **残す** — 根拠種類、本人確度、適用範囲を分け、出典、例外、確認日も短く記録する。
4. **使う** — 返信や提案など、次の実際の用事で読み込む。
5. **直す** — 「ここは自分らしくない」を直し、プロフィールも必要な部分だけ更新する。

たとえば「丁寧な返信が好き」だけでは、何が丁寧なのかは伝わりません。
「断るときも、誘ってくれたことへのお礼と、参加できない理由を短く伝えたい」のように、場面と選ぶ行動まで書くと使いやすくなります。

## 何を記録するのか

| 観点 | 手掛かり |
| --- | --- |
| 自分の背景 | 今の役割、続けてきたこと、転機 |
| 好み・特徴 | 好き嫌い、得意な進め方、疲れやすい条件 |
| 価値観 | 大切にしたいこと、譲りたくないこと、その理由 |
| 判断の仕方 | 二つとも大事なとき何を優先するか、例外 |
| 自分の言葉 | 好きな文章とその理由、相手による言い方の違い |
| 関心・目標 | 今取り組みたいこと、まだ決めていないこと |
| AIとの協働 | 任せたい範囲、相談したい場面、避けたい対応 |

話したくないことは飛ばせます。住所や連絡先、健康情報などを全部集める必要はありません。本人の好みを記録することと、その好みが客観的に正しいと扱うことも別です。

## 自分らしさを確かめる

AIに「本人そのものになれた」と自己採点させず、実際の出力を自分で見ます。

- 自分が言いそうなことか。言っていない経験や意見が増えていないか。
- 自分の理由が伝わっているか。口調を似せただけになっていないか。
- 今の相手や目的に合っているか。毎回同じ好みを押し込んでいないか。

会話での修正を次の出力にも反映できたら、一歩進んだと考えます。人格の完全な複製や、判断の正しさを保証するものではありません。

## 保存と公開

公開するのは、この空のスキル、質問、説明、架空の例です。個人の記入版は別の非公開フォルダーや非公開メモに置きます。個人データを一度コミットしてから消す方法は使いません。Gitの過去の履歴に残るためです。

AIに読ませる内容は、利用するAIサービスにも渡ります。公開しないことと、そのサービスへ渡さないことは別なので、自分が渡してよい内容を選んでください。メールの相手など第三者の情報は、必要な部分だけに絞れます。

プロフィールには、メール送信や投稿を一括で許可する権限はありません。外部への行動は、その時の依頼に従います。
