# 初期設定

初回導入や、保存先・読み込み方を見直すときに使う。ここで整えるのは、必要な記録を安全に読んで使い、許可された範囲で保存・訂正できる手順。全プロフィールの記入や人物像の完成は完了条件ではない。

## AIが確認すること

1. **保存先と既存情報**：現在の依頼で指定された正本と、許可された範囲で見える非公開の保存先を確認する。既存記録があれば今回に必要な部分を実際に読み、正本を尊重する。読めないものを既読にせず、全文を別の場所へ複製しない。未指定なら、まず会話内の案として扱う。
2. **許可範囲**：読み取り、記入案の作成、保存、訂正のどこまで頼まれているかを、現在の依頼から確認する。ツールの書き込み権限があることを、本人からの保存許可に置き換えない。明確に許可された作業は、同じ承認を取り直さず進める。
3. **保存先の適性**：候補が非公開で、公開スキルや公開リポジトリの外にあるかを確かめる。公開リポジトリ内の無視対象フォルダーも記入版の保存先に選ばない。場所の公開範囲が分からなければ、そこへの保存を止めて会話内の案を示す。
4. **読み取り・訂正の検証**：保存や訂正が許可され、先と内容が明確なら、必要な部分だけ変更して読み直す。明確な訂正は現行情報へ反映し、古い情報と矛盾したままにしない。書き込みの応答だけで保存済みと判断せず、読み直せなければ検証未完了と伝える。検証のためだけの不要な書き込みはしない。

## 本人に聞くこと

AIが確認できる保存先の状態、既存情報、アクセス可否、変更結果を質問で代替しない。既に分かっている指定や許可も問い直さない。質問は、複数の正本候補からどれを選ぶか、未指定の保存先をどこにするか、どの内容の保存を許すかなど、本人しか決められず今回の作業に必要なことだけに絞る。保存を求めていなければ、保存先選びで成果物の作成を止めない。

## 保存しない場合

- 会話だけで整理したい、または保存を許可されていない場合は、会話内の案を示すだけにする。
- 保存先が公開、公開範囲が不明、公開リポジトリ内、または書き込みできない場合は、そこへ記入版を保存しない。「保存済み」とは言わず、非公開の保存先が必要なことを伝える。
- 実ユーザーの個人情報、会話原文、個人資料のURLは公開スキル、README、Issue、PRへ入れない。公開説明には空のひな形と架空例だけを使う。

## 初期設定の完了

会話内の案だけで進めるか、確認できた非公開の正本を使うかが決まり、今回の許可範囲で読み取り・保存・訂正を実行または未実行と区別できればよい。保存を行った場合は読み直しの結果を示す。未確認項目は残したまま、今回の成果物や仕組みの差分提案へ戻る。

次回の読み込み方も短く示す。自動参照を実際に設定・確認していなければ、自動で読まれるとは言わず、次回に記入版とスキルを渡す方法を案内する。
