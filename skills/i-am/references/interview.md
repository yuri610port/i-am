# 対話の進め方

これは質問票を全部埋める面接ではない。本人が今使いたい場面から始め、通常は一度に一つ聞く。本人がまとめて答えたければ合わせる。短い回答や「まだ分からない」もそのまま受け取る。

## 最初の一問

すでに文章や修正理由が出ていれば、それを使う。何もなければ、例えば次から一つを選ぶ。

- 最近、AIの文章や提案に「自分ならこうしない」と思った場面はあるか。
- 最近、自分で選んでよかったことは何か。
- AIに自分のことを一つだけ覚えてもらうなら、何を伝えたいか。

思いつかない人には、日常の小さな選択でよいと伝える。具体例を出すなら、選択肢にない答えも認める。性格や価値観を誘導する選択肢にしない。

## 理由を一段掘る

「好き」だけでは次に使いにくい場合に、その理由か具体的な場面を聞く。既に理由が分かっていれば、深掘りを続けない。

- その文章の、どの部分が自分と違ったか。
- 二つの案からこちらを選んだ決め手は何か。
- 同じ選び方をしない場面はあるか。
- それを大事にするようになった出来事はあるか。話したい範囲だけでよい。

## 観点を広げるとき

| 観点 | 質問の例 |
| --- | --- |
| 背景・転機 | 今の考え方に影響した経験はあるか。 |
| 好み・特徴 | 楽に続けられることと、負担になることは何か。 |
| 価値観 | 成果が同じなら、どんなやり方を選びたいか。 |
| 優先順位 | 速さと納得感など、二つとも大事なときは何で決めるか。 |
| 対人関係 | 相手の意見と違うとき、どう伝えたいか。 |
| 表現 | 自分で「この言い方なら出せる」と思う文章はどれか。 |
| 目標 | 今は何を増やしたいか、何を減らしたいか。 |
| 変化 | 昔と今で、考えが変わったことはあるか。 |
| 協働 | AIに任せると助かる部分と、自分で決めたい部分は何か。 |

## まとめて試す

例えば「断るときも関係を続けたいので、お礼と短い理由を伝えることを大事にしている、と受け取った」と、解釈を短く示す。本人が明言した内容以上の解釈なら未確認として扱う。

次に小さな文章や提案を作り、本人の反応で確かめる。「100点中何点か」より「どこを自分の言葉に直したいか」が役に立つことがある。

本人が今日はここまでと言ったら、分かったこと、未確認のこと、保存した場所を示して終える。次の質問を機械的に続けない。
