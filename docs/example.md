# 架空の会話で見る I am

人物、出来事、文章はすべて説明用に作ったものです。利用者のプロフィールへ取り込まないでください。

## 1. 違和感から始める

架空の利用者は、週末の読書会への誘いを断る返信を頼みました。

**最初の案**

> お誘いありがとうございます。予定があるため今回は参加できません。また機会がありましたらよろしくお願いいたします。

**利用者の感想**

> 断るだけだと冷たく感じる。今回は家で休みたいけれど、その会には興味がある。読んでいない本を「好き」と言うのは嫌だな。

**AIの整理**

> 今回は「参加できない理由」と「会への関心」を両方伝えたいんだね。読んだことや好みを作らない、という点も記録するよ。

## 2. 小さく記録する

- 内容：今回の誘いは断るが、会への関心を短く伝えたい。
- 理由・具体例：断るだけだと冷たく感じる。読んでいない本を好きだとは書きたくない。
- 使う場面：今回の読書会への返信。
- 例外・使わない場面：他の誘いでも必ず関心を示したいかは未確認。
- 状態：本人確認済み。
- 根拠：上の架空の利用者の発言。
- 確認日：デモのため省略。

「内向的」「読書家」「誘いはいつも断る」といった性格や習慣は記録しません。

## 3. 文章に使う

**修正案**

> 誘ってくれてありがとう。今週末は家でゆっくり休みたいので、今回は見送らせてね。読書会には興味があるから、また開催するときに教えてもらえたらうれしいです。

**利用者の追加修正**

> 相手はまだ親しくない人だから、もう少し丁寧に。自分を休ませる理由は「予定がある」でいい。

**完成案**

> お誘いありがとうございます。今週末は予定があるため、今回は見送らせてください。読書会には興味がありますので、また開催される際に教えていただけたら嬉しいです。

記録には「今回の相手には丁寧語」「休むという私的な事情はそのまま相手へ伝えない」を追加します。AIが本人を理解するために知ったことを、全部相手に書く必要はありません。

## 4. 別の用事で確かめる

次の返信で、同じ表現をコピーするのではなく、今回の相手と本人の気持ちに合うかを確かめます。本人が関心を示していない新しい催しに、AIが勝手に「興味があります」と書いてはいけません。
